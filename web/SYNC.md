# Cloud Sync Guide

## Enable Cloud Sync

The GymTracker has two versions:

### 1. **GitHub Version** (Local Only)
- Opens directly from GitHub  
- Saves only on your device
- No cross-device sync

### 2. **Claude Artifact Version** (Cloud Sync) ⭐ RECOMMENDED
- **URL**: https://claude.ai/artifact/Lbiv2FAn6yzSaBSWgTGPpa
- Syncs across phone & laptop automatically
- Secure cloud backup
- No setup required - just open and start logging

## How Cloud Sync Works

When you open the **Claude Artifact version**:
1. App connects to cloud on startup
2. Downloads your existing workouts (if any)
3. Uploads any new workouts you log
4. Status indicator shows sync status:
   - 🟢 **Saved** = Connected and synced
   - 🟡 **Saving** = Uploading your workout
   - 🔴 **Error** = Connection issue (data saved locally, will sync when back online)

## Use the Cloud Version

1. **Open the artifact**: https://claude.ai/artifact/Lbiv2FAn6yzSaBSWgTGPpa
2. **On phone**: Bookmark it in your browser
3. **On laptop**: Open the same link
4. Start logging - everything syncs automatically!

## FAQ

**Q: Can I use both versions?**
A: No, they don't share data. Pick one and stick with it.

**Q: Is my data private?**
A: Yes! Data is encrypted and only you can access it.

**Q: What if I don't have internet?**
A: Workouts save locally and sync automatically when you reconnect.

**Q: Can I export my data?**
A: Yes! In History tab, there's an "Export CSV" button (cloud version only).
