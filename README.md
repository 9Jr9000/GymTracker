# GymTracker

A comprehensive workout tracking application for logging exercises, tracking progress, and analyzing fitness metrics.

## Features

- **Workout Logging**: Log exercises by body part with sets, weight, and reps
- **Progress Tracking**: Track PRs, volume, and estimated 1RM calculations
- **History View**: Review past workout sessions
- **Progress Charts**: Visualize progress over time
- **Local Storage**: All data stored in browser (no server required)
- **Rest Timer**: Built-in timer between sets
- **Smart Defaults**: Auto-fills from previous sessions

## Usage

Open `web/index.html` in a web browser to start using the tracker.

## Workout Plan

Default workout split:
- **Legs**: Squats, Romanian deadlifts, leg extensions, curls
- **Back & Chest**: Incline press, chest flyes, rows, pull-ups
- **Tri & Bi**: Cable pushdowns, dips, curls, shoulder work
- **Back & Bi**: Pull-ups, rows, shrugs, curls
- **Chest & Tri**: Incline press, close-grip press, cable work, dips
- **Abs**: Cable crunches, dead bugs, planks
- **Forearm**: Wrist curls, farmer's carries

## Data Storage

- Workouts are stored in browser localStorage
- No internet connection required
- Data persists across sessions
